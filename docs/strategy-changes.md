# 策略配置与变更环境

已对照 Zeus 内容安全空间的变更环境页面与前端实现，保留顶部隔离提示及“取消变更、批量变更、变更内容、紧急变更、去实验”入口。读取来源时不写入 Zeus；实际编辑、发布和回滚均发生在本仓库服务的 SQLite 中。

## 生效约束

- 规则只要在任一普通、分层或路由场景生效（含灰度），其定义、删除、历史版本恢复和已有策略配置调整均必须进入策略变更。后端实施约束，不能仅绕过按钮发请求修改。
- 规则组新增规则只能选择离线或标记；新增规则同步到已有规则组挂载位置。没有生效引用的既有规则可直接调整或移除；有生效引用时，线上规则组编辑和删除不可用。
- 规则组保留批量操作、最后修改时间/修改人、规则标签及风险标签筛选；移除行内策略变更和引用按钮，从全局变更入口进入任务。

## 隔离、发布和同步

每个变更任务拥有独立草稿，通过 `changeTaskId` 传递上下文。查看规则、规则组、普通场景和分层节点时叠加该任务草稿；新开规则详情保留任务参数。未知任务或不受支持的变更写操作直接拒绝，不退回线上写入。

修改规则定义后，所有引用该规则的场景在发布时读取更新后的定义；修改单个场景策略只调整该场景配置；修改规则组策略则同步规则组的全部挂载配置，包括分层节点。删除规则会删除规则实体、引用配置和特征引用。多项变更在同一事务内发布，线上配置已经变化时拒绝陈旧草稿，避免部分发布。

“取消变更”退出环境并保留草稿，可从任务详情重新进入。“去实验”进入实验配置页；“紧急变更”进入灰度配置并填写原因。实验/审批后冻结草稿，最终发布时才写入线上配置；紧急变更同样不直接修改线上数据。发布保存快照，回滚恢复规则定义及相关配置；若发布后数据已被其他操作修改，则拒绝覆盖。

## 规则与风险标签

新建规则的三个环节为逻辑信息、测试、属性信息。交互式条件支持编号表达式，例如 `1&&(2||4)||3`、`!1||(2&&3)`，可以重复引用条件；服务端模拟计算采用解析器，不执行任意代码。模拟器覆盖布尔组合与基础比较，不等同于完整 Aviator 引擎。

引用统计区同时列出 Zeus 快照引用次数/决策比例，以及本副本实际引用配置数。全量规则定义不代表已经导入所有场景引用，两个数字可能不同，比例不会被伪造为次数。风险标签按 `parentId` 构建父子树，规则组及规则列表选中父标签时包含子标签。

## 验证

`npm test` 验证直接修改拦截、草稿隔离、分页与标签筛选、跨场景同步、删除级联、原子发布、配置冲突、回滚、紧急变更和自定义条件逻辑。`npm run build` 检查类型与生产构建。另用隔离内存数据库完成浏览器操作验收：生效策略进入变更环境、恢复编辑框、变更内容、实验页跳转、发布、规则组按钮/标签树及条件逻辑输入；不在源平台创建测试数据。

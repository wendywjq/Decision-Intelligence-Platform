## 数据存储与使用

`fixtures/zeus-examples/` 保存来源数据包的压缩分片，启动时按 manifest 顺序组合并校验 SHA-256；`fixtures/zeus-examples-manifest.json` 记录选择范围、计数、摘要哈希和来源差异。后端首次启动或快照变化时自动导入 SQLite。

```bash
npm ci
npm run dev
npm test
npm run verify:source
```

普通场景和规则组可展开其配置；规则详情可查看交互式条件、原始表达式、引用特征和被引用情况。分层场景可切换识别树、决策树、模板和版本列表，点击节点查看策略与路由/短路配置。风险标签支持完整树、ID/编码/名称搜索。

变更管理可查看变更前后内容及影响场景、实验对比与请求ID明细、灰度阶段配置和对比数据；支持创建本地变更任务与复制来源任务内容。来源快照只读保存，策略配置编辑及画布布局保存仅影响本地副本。

原始规则的历史版本和测试用例仅在来源响应包含时展示；此批次的规则定义通过批量只读接口抓取，没有导出每一条规则的全量历史。

参数与因子使用不同命名空间。界面展示原始特征ID；数据库内部为参数使用 `1000000000 + 原始ID`，以免与因子ID冲突。

## 校验

- 10 个指定普通场景、3 个分层场景、4 个指定规则组及5个任务全部存在。
- 普通场景配置 11,260 条；规则组配置 11,147 条；保留同一规则在不同组/节点中的重复引用。
- 所有已捕获配置的规则与规则组引用均能解析。
- 风险标签数与源端 `riskCount` 一致：1,052。
- 实验请求ID明细按源端总数完整分页；灰度表的源计数差异单独标记。
- 样例包不包含 Cookie、SSO 令牌或网络认证头。

抓取工具默认单路、相邻新请求至少间隔1秒，限流后冷却60秒并复用成功响应缓存。`data/zeus-source` 是本地抓取缓存，不提交。
